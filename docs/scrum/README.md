# Scrum records

How the team runs each sprint, and the evidence for it. Jira holds the live
board; these pages record what each sprint committed, what it delivered, what
changed during it, and what the team decided to change next.

| Page | What it records |
|---|---|
| [Sprint 1](sprint-1.md) | 9 to 23 Sep 2026: request to approval, gated by role |
| [Sprint 2](sprint-2.md) | 23 Sep to 7 Oct 2026: every main flow end to end |
| [Sprint 3](sprint-3.md) | 7 to 21 Oct 2026: Release 1 with the Week 7 changes |
| [Estimation and velocity](estimation.md) | The point scale, reference stories, velocity per sprint, every re-estimate |
| [Definition of Done](definition-of-done.md) | When a story counts as Done, and where each rule is enforced |

Screenshots and CI logs captured for sprint reviews are in
[`docs/evidence/`](../evidence/).

## How these pages are kept

- **Figures come from Jira or git**, and each says where it came from. They
  were read through the Atlassian MCP on the date the page gives; Jira stays
  the source of truth (CLAUDE.md).
- **Sections only the team can write** (sprint review outcomes, Product Owner
  acceptance, the retrospective) are marked *To be completed by the team*.
  Nobody fills them in for the team, including an AI assistant.
- **Update a sprint's page at its review and retrospective**, and the
  velocity table in [estimation.md](estimation.md) when the sprint closes.
